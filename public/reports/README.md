# PDF font provenance

`NotoSans-Regular.ttf` is the static hinted Noto Sans font from
`https://github.com/notofonts/notofonts.github.io/blob/main/fonts/NotoSans/hinted/ttf/NotoSans-Regular.ttf`.
Downloaded 2 October 2026. SHA-256:
`478C558EA716033CD60C03438F628DFA75694DCF6B5F6D505A2F05FD2B4F3823`.
The accompanying `OFL.txt` is the SIL Open Font License for Noto Sans.

The variable font from Google Fonts did not render reliably in `pdf-lib`;
the static file passed rendered page inspection with Māori macrons.
